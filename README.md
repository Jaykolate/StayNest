# StayNest

StayNest is a **full-stack web application** for listing and reviewing stays (similar to Airbnb).  
It lets users sign up, create listings, add reviews, and explore stays — built with **Node.js, Express, EJS, MongoDB, and Bootstrap**.

---

## 🛠️ Features

✔ User Authentication (Signup/Login)  
✔ Create, Read, Update, Delete Listings  
✔ Add Reviews to Listings  
✔ MVC Architecture  
✔ EJS Templating  
✔ Organized Routes, Controllers, and Views

---

## 🚀 Tech Stack

**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**Views:** EJS  
**CSS/Frontend:** Bootstrap, Custom CSS  
**Others:** Cloudinary for image uploads, Mongoose ORM
